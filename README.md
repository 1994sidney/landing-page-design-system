# Landing Page Design System

用于持续迭代 Landing Page 视觉语言与组件规范的独立设计仓库。

当前方向基于 LeRoux 的现代商业视觉语言，并针对中文简体网页进行了重新整理与适配：

- 中文实心字体与更适合中文阅读的字号、行高、字距
- 雾蓝灰主题色与明确的背景、文本、表面、卡片色角色
- 大面积留白、摄影主导、低对比内容表面
- 减少分割线与边框卡片
- 克制使用毛玻璃效果
- 适用于 Landing Page / 品牌官网 / 专业服务与教育科技类页面

## 文件

- `index.html`：当前完整 Design System，可直接在浏览器打开预览
- `README.md`：设计系统说明与后续迭代记录

## 后续迭代原则

优先在本仓库继续调整视觉系统与 Landing Page 组件。除非明确要求，不与其他业务项目合并，也不自动部署到 Vercel。
