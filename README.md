# Landing Page Design System

用于持续迭代 Landing Page 视觉语言与组件规范的独立设计仓库。

当前设计方向基于 LeRoux 的现代商业视觉语言，并针对中文简体网页重新整理：中文实心字体、雾蓝灰主题、编辑式排版、低饱和摄影、减少线框与卡片边框，以及克制使用毛玻璃效果。

## 当前结构

```text
landing-page-design-system/
├── index.html            # 页面结构与全部组件示例
├── script.js             # 滚动显现、页签、FAQ 等轻量交互
├── styles/
│   ├── base.css          # 基础样式入口

│   ├── v2.css            # 当前视觉优化样式入口
│   └── v2/               # V2：主题色、毛玻璃、减线框等覆盖样式
└── README.md
```

## 设计方向

- 中文字体优先：苹方、思源黑体、微软雅黑等系统无衬线字体
- 不使用空心大字，中文标题依靠字号、字重、留白建立气场
- 主题色：`#7B8E90`
- 深背景：`#20282A`
- 页面背景：`#F1F2F0`
- 内容表面：`#FAFAF8`
- 卡片 / 面板：`#E3E7E5`
- 主文本：`#202629`
- 次文本：`#5E6869`
- 毛玻璃：建议 `rgba(248,250,249,.58)` + `blur(18px)`，只用于导航、叠图信息、表单等浮层场景
- 减少贯穿式分割线、表格感和边框卡片，更多通过留白、底色、摄影与不对称布局建立层级

## 本地预览

建议使用一个简单的静态服务器，而不是直接双击 HTML：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 后续迭代

后续可以直接围绕本仓库继续调整首屏、主题色、字体、Landing Page 组件、动效、摄影方向和完整页面模板。除非明确要求，本仓库不会与其他业务工程合并，也不会自动部署到 Vercel。
